# 证据与工具选择

| 来源 | 可以支持 | 不能单独支持 |
|---|---|---|
| 实际操作及可观察结果 | 给定身份、时间、环境、输入下的样本结果 | 所有账号/条件均如此 |
| 页面入口、文案或确认框 | 页面呈现和可见入口 | 后端执行、持久化和完整结果 |
| 截图、脱敏事件或原始记录 | 留存范围内可复核的观察 | 未记录的步骤或因果 |
| 源码与配置 | 所检查版本的设计或实现 | 当前线上部署、授权或实际运行必然一致 |
| 历史验收与文档 | 指定时间/版本、文档所述行为 | 现行部署不变或用户实际完成 |
| 推测 | 后续验证方向 | 已证实原因或产品不支持 |

记录目标部署、角色、时间及版本；不可得则未知。证据索引写路径及支持的结论；只有现场观察或文字转述时如实写明。不要把业务记录“创建成功”当作执行成功。

工具按需选用：用户现有材料和连接器优先；浏览器用于核验入口、分支和结果，先核对测试身份与地址；协议问题且已授权时使用开发者工具，避免导出凭据、Cookie、签名 URL 和敏感请求体。源码/REA 按需用于解释实现，明确版本与证据层级。Mermaid 和交互图只能检查已录入内容，不能证明所有任务已发现；录制/回放前核对写入、付费和删除副作用。同步私有证据前检查秘密、身份及去向，按用户授权范围处理。
