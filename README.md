适用于产品、设计与研发人员调研管理后台、SaaS 或单个产品模块；也可按同一用户任务比较两个产品。它处理用户交互路径，不替代代码审计或二进制逆向。

## ✨ 功能

- **任务优先**：记录入口、前提、操作与最终结果。
- **证据可追溯**：区分现场样本、页面提示与待验证项。
- **路径可视化**：用 Mermaid 表达模块与跨模块路径。
- **产品对比**：对齐用户目标，输出差异和验收建议。

## 🚀 快速开始

需要 Git 和已安装的 Codex CLI。以下命令将完整 Skill 安装到 `~/.agents/skills/`；若该位置或旧目录存在同名文件、目录或软链接，将停止以避免覆盖。

```sh
repo_tmp="$(mktemp -d)"
dst="$HOME/.agents/skills/z-product-path-research"
legacy="$HOME/.codex/skills/z-product-path-research"
if [ -e "$dst" ] || [ -L "$dst" ] || [ -e "$legacy" ] || [ -L "$legacy" ]; then
  printf '%s\n' '同名 Skill 已存在，停止安装。'
else
  if git clone --depth 1 https://github.com/score2021/z-product-path-research.git "$repo_tmp/source"; then
    mkdir -p "$(dirname "$dst")"
    cp -R "$repo_tmp/source" "$dst"
    rm -rf "$dst/.git"
    printf '%s\n' "已安装到 $dst"
  else
    printf '%s\n' '仓库下载失败，请检查网络和仓库地址。'
  fi
fi
rm -rf "$repo_tmp"
```

打开新的 Codex 会话，输入 `$z-product-path-research` 和具体任务。若技能列表尚未刷新，重启客户端后重试。当前安装位置和行为仅在 Codex CLI 测试；其他客户端需自行确认发现路径。

## 🧭 工作方式

1. 对齐角色、产品版本、环境、用户任务和成功条件。
2. 盘点入口及依赖，先试点一条任务，再按模块完成主要路径。
3. 将入口、动作、可见反馈、最终结果、失败和恢复分别记录，并连接证据。
4. 绘制模块图与按需汇总的跨模块图；对已验证样本、未验证和阻塞清楚标注。
5. 对照产品时，按相同目标比较用户影响、证据和待验项，再提出可验收的改进建议。

浏览器、开发者工具和状态模型按任务需要选用；Skill 不自带浏览器，也不会自动安装图工具。执行产生费用、上传或修改资源的动作需遵循具体用户授权及运行环境规则。原始证据可能包含敏感信息，分享前应检查和脱敏。
